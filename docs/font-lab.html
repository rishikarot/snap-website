Start with Gabarito throughout against Bricolage + Gabarito. Switch either side to earlier options. Test real controls, small captions, money, and letter shapes. These are illustrative examples; nothing submits to SNAP.

My recommendation

Gabarito throughout is my first choice for a friendly, coherent professional identity. Bricolage + Gabarito gives the marketing a more expressive voice. Fredoka and Baloo 2 remain useful comparisons, but their playful character needs restraint.

  • Read the small task labels and financial figures before judging the hero.
  • Compare 1 / I / l, 0 / O, currency signs, and long names.
  • Try mobile width. A distinctive font still needs comfortable wrapping.
  • Keep the original logo. The supporting typography should complement it.
